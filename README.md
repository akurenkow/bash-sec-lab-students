# Лабораторные по bash для специалистов по ИБ

Две связные лабораторные: сначала основы командной строки глазами
безопасника (права, пользователи, поиск следов), затем анализ логов
и автоматизация расследования скриптами.

## Как работать

1. Задания в папках `lab1/task01-...` … и `lab2/task01-...` — по порядку.
2. В каждой папке — `README.md` с подробными шагами. Пропуски `____`
   и пометки **ВПИШИТЕ** заполняете сами.
3. Данные для анализа — в папке `data/` (учебные логи с «атакой»).
4. `pro01`…`pro10` — задачи на самостоятельную работу: цель и критерии
   приёмки есть, готовых команд почти нет.
5. В конце каждого README — что сдать в отчёт.

## Этика

Все приёмы выполняем на своих файлах и своём стенде. Те же команды
против чужих систем без разрешения — статья. Мы учимся **защищать**.
