# Задание 2. Права доступа: rwx и chmod

**Что делаем:** разбираемся в правах — фундаменте безопасности Linux.

## Шаг 1. Посмотрите на права

Из папки `data/practice_tree`:

```bash
ls -l app/config/
```

Строка вида `-rw-r--r-- 1 user staff 24 ... .env` читается так:

```
- rw- r-- r--
│  │    │   └── остальные: только чтение
│  │    └────── группа: только чтение
│  └─────────── владелец: чтение+запись
└────────────── обычный файл (d — каталог)
```

## Шаг 2. Проблема

Права `.env` сейчас `644` — пароль из базы **читают все пользователи
системы**. Так делать нельзя.

## Шаг 3. Исправьте

chmod с числами: r=4, w=2, x=1. Владелец rw (4+2=6), остальным — ничего:

```bash
chmod ____ app/config/.env
```

ВПИШИТЕ трёхзначное число: владелец — чтение+запись, группа и остальные —
ничего. Проверьте: `ls -l app/config/`.

## Шаг 4. Сделайте скрипт исполняемым

```bash
echo 'echo "привет"' > hello.sh
./hello.sh          # Permission denied — почему?
chmod +x hello.sh
./hello.sh
```

## Шаг 5. Ответьте письменно

1. Расшифруйте права `rwxr-x---` и запишите их числом.
2. Почему `chmod 777` — почти всегда плохая идея?
