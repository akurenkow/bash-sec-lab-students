# Задание 7. Перенаправления: фиксируем улики

**Что делаем:** сохраняем результаты команд в файлы-отчёты.

**Зачем безопаснику:** при расследовании каждый шаг документируется.
«Я видел это в консоли» — не доказательство; файл с датой — уже лучше.

## Шаг 1. Создайте файл-отчёт

Из корня репозитория:

```bash
echo "ОТЧЁТ ПО РАССЛЕДОВАНИЮ" > report.txt
date >> report.txt
```

Разница: `>` перезаписывает файл, `>>` дописывает в конец.

## Шаг 2. Добавьте улику

```bash
echo "--- Неудачные входы:" >> report.txt
grep "Failed password" data/auth.log | wc -l >> report.txt
```

## Шаг 3. Ошибки тоже перенаправляются

```bash
ls /несуществующий-каталог
ls /несуществующий-каталог 2> errors.txt
cat errors.txt
```

`2>` — поток ошибок (stderr). Частая связка: `команда > out.txt 2>&1` —
и вывод, и ошибки в один файл.

## Шаг 4. Проверьте отчёт

```bash
cat report.txt
```

## Результат

**В отчёт:** содержимое `report.txt` и ответ на вопрос:
что произойдёт с содержимым report.txt, если в шаге 1 вторую команду
записать с `>` вместо `>>`?

> После задания файлы можно удалить: `rm report.txt errors.txt`.
