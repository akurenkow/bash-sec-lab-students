# Задание 4. find: поиск файлов и следов

**Что делаем:** ищем файлы по имени, типу и времени — базовый навык
расследования инцидентов.

Все команды — из папки `data/` (поднимитесь туда: `cd data` из корня
репозитория).

## Шаг 1. По имени

Найдите все логи в учебном дереве:

```bash
find practice_tree -name "*.log"
```

## Шаг 2. По типу

Только каталоги:

```bash
find practice_tree -type d
```

## Шаг 3. Недавно изменённые

Вопрос из жизни: «что менялось на сервере за последние сутки?»

```bash
find practice_tree -mtime -1
```

## Шаг 4. Поиск SUID-файлов (главное для безопасника)

SUID — бит, при котором программа выполняется с правами **владельца**
(например, root), а не того, кто её запустил. Лишний SUID — классический
путь повышения привилегий. Команда аудита:

```bash
find /usr/bin -perm -4000 2>/dev/null | head
```

Разбор: `-perm -4000` — установлен SUID-бит; `2>/dev/null` — спрятать
ошибки «permission denied».

Почему атакующий, получивший доступ к серверу, первым делом выполняет
именно `find / -perm -4000`? Что он ищет?
