# Задание 5. grep: ищем в логах

**Что делаем:** первый контакт с логом аутентификации — ищем неуспешные
входы.

Файл: `data/auth.log` — журнал SSH-сервера (учебный, с «атакой»).

## Шаг 1. Просто посмотрите

```bash
head -5 data/auth.log
```

## Шаг 2. Найдите все неудачные попытки входа

```bash
grep "Failed password" data/auth.log | head -5
```

## Шаг 3. Посчитайте их

Конвейер: результат первой команды передаём во вторую:

```bash
grep "Failed password" data/auth.log | wc -l
```

## Шаг 4. А сколько было успешных?

ВПИШИТЕ слово, по которому искать успешные входы
(подсказка: антоним Failed в этом логе):

```bash
grep "____" data/auth.log | wc -l
```

## Шаг 5. Найдите конкретного пользователя

Кого пытались взломать? ВПИШИТЕ имя:

```bash
grep "Failed password" data/auth.log | grep "____" | head -3
```

(посмотрите сначала глазами в выводе шага 2, какие логины фигурируют.)

## Результат

**В отчёт:** три числа — количество Failed, количество успешных,
и логин(ы), которые атаковали.
