# Задание 1. Навигация и скрытые файлы

**Что делаем:** учимся перемещаться по файловой системе и находить
скрытые файлы — любимое место для секретов и «закладок».

## Шаг 1. Где мы

```bash
pwd
```

## Шаг 2. Перейдите в папку данных

```bash
cd data/practice_tree
ls
```

## Шаг 3. А теперь — всё, включая скрытое

```bash
ls -la
```

Файлы и папки, начинающиеся с точки, обычным `ls` не видны.
Найдите скрытый файл в `app/config/`. Откройте его:

```bash
cat app/config/.env
```

Вот почему `.env` нельзя коммитить в git — там пароль.

## Шаг 4. Путь туда и обратно

```bash
cd app/logs
pwd
cd ../..      # на два уровня вверх
pwd
```

## Шаг 5. Ответьте письменно

1. Чем отличается `cd ..` от `cd ../..`?
2. Какой командой показать размер файлов в удобном виде
   (Кб/Мб вместо байт)? Подсказка: флаг `-h` у ls.

## Результат

**В отчёт:** вывод `ls -la app/config/` и содержимое найденного
скрытого файла.
