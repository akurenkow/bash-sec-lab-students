# Задание 6. Процессы: кто что запустил

**Что делаем:** смотрим список процессов и убиваем «подозрительный».

**Зачем безопаснику:** вредонос на заражённой машине — это процесс.
Умение найти чужой процесс среди сотен своих — база.

## Шаг 1. Запустите «подозрительный процесс»

```bash
sleep 5000 &
```

`&` — запуск в фоне. Представьте, что это чужая программа, висящая
в системе.

## Шаг 2. Найдите его

```bash
ps aux | grep sleep
```

Разбор: `ps aux` — все процессы всех пользователей; через конвейер
grep оставляет нужные строки. (Строка с самим grep — не в счёт,
это сам процесс поиска.)

Колонки: USER, PID (второй столбец), %CPU, %MEM, команда.

## Шаг 3. Убейте процесс

ВПИШИТЕ PID из шага 2:

```bash
kill ____
```

Проверьте: `ps aux | grep sleep` — процесса нет (остался только grep).

## Шаг 4 (по желанию). Живая картина

```bash
top
```

Выход — `q`.
