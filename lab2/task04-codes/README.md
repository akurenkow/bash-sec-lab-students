# Задание 4. HTTP-коды: картина по серверу

**Что делаем:** сводку кодов ответов веб-сервера — что вообще происходит
с сайтом.

## Шаг 1. Распределение кодов

Соберите известным приёмом (код — девятое поле):

```bash
awk '{print $9}' data/access.log | sort | uniq -c | sort -rn
```

## Шаг 2. Что за 404

Много 404 — либо битые ссылки, либо сканирование. Посмотрите, какие
пути запрашивали (путь — седьмое поле). ВПИШИТЕ номер поля:

```bash
awk '$9 == 404 {print $__}' data/access.log | sort | uniq -c | sort -rn
```

## Шаг 3. Кто сканирует

Пути вида `/admin`, `/.env`, `/wp-login.php` на сайте, где их нет, —
это сканер на поиск уязвимостей. Найдите IP, который их дёргал:

```bash
grep "/.env" data/access.log
```
