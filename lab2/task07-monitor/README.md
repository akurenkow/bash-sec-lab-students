# Задание 7. Живой мониторинг лога

**Что делаем:** «дежурную смену» — смотрим лог в реальном времени
и ловим событие в момент его появления.

## Шаг 1. tail -f

Откройте терминал и выполните:

```bash
tail -f data/auth.log
```

`tail -f` показывает конец файла **и все новые строки по мере
их появления**. Команда «висит» — это нормально, она дежурит.

## Шаг 2. Сгенерируйте событие

Во **втором** терминале добавьте строку в лог:

```bash
echo "Nov 19 23:59:59 server sshd[9999]: Failed password for root from 10.9.9.9 port 1234 ssh2" >> data/auth.log
```

Вернитесь к первому терминалу — строка появилась на глазах.

## Шаг 3. Мониторинг с фильтром

Остановите tail (Ctrl+C) и запустите с фильтром — только неудачные входы:

```bash
tail -f data/auth.log | grep --line-buffered "____"
```

ВПИШИТЕ шаблон. Добавьте из второго терминала ещё одну строку —
сначала с "Accepted password" (не должна показаться), потом
с "Failed password" (должна показаться).

(`--line-buffered` нужен, чтобы grep не копил вывод, а показывал
сразу.)

## Шаг 4. Завершите мониторинг

Ctrl+C.
