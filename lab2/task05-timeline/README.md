# Задание 5. Таймлайн: события за окно времени

**Что делаем:** вырезаем из лога события конкретного часа — базовый приём
при восстановлении хронологии инцидента.

## Шаг 1. Все события 14 часа (auth.log)

```bash
grep "Nov 19 14:" data/auth.log | wc -l
```

## Шаг 2. Окно поуже: с 14:30 до 14:59

Подсказка: время в начале строки идёт как `14:3x` или `14:5x`.
ВПИШИТЕ диапазон символов минут:

```bash
grep "Nov 19 14:[3-5]__" data/auth.log | wc -l
```

(квадратные скобки в grep — «один символ из набора».)

## Шаг 3. Таймлайн атаки на веб

Когда сканер начал и закончил работу? В access.log время выглядит
как `[19/Nov/2026:13:12:05`. Вытащите все запросы сканера и посмотрите
на первый и последний:

```bash
grep "203.0.113.99" data/access.log | head -1
grep "203.0.113.99" data/access.log | tail -1
```

## Шаг 4. Ответьте письменно

За сколько минут сканер прошёл свои цели? Почему такие всплески
и видны в логах, и ловятся системами защиты?

## Результат

**В отчёт:** числа из шагов 1–2, время старта и конца сканирования.
