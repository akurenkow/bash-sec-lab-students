# Задание 2. awk: режем лог на колонки

**Что делаем:** то же, что в task01, но по-взрослому — awk умеет
работать с колонками напрямую.

## Шаг 1. Первая колонка

```bash
awk '{print $1}' data/access.log | head -3
```

`$1` — первое поле (по умолчанию разделитель — пробелы).

## Шаг 2. HTTP-код — девятое поле

```bash
awk '{print $9}' data/access.log | head -3
```

## Шаг 3. Колонки вместе

IP + код ответа:

```bash
awk '{print $1, $9}' data/access.log | head -5
```

## Шаг 4. Фильтр по условию

Только запросы с кодом 404 (колонка 9 равна 404). ВПИШИТЕ номер колонки:

```bash
awk '$__ == 404' data/access.log | head -5
```

## Шаг 5. Комбо

Топ IP среди только 404-ых — соберите конвейер сами из известных деталей
(awk-фильтр → вырезать IP → топ):

```bash
awk '$9 == 404 {print $1}' data/access.log | ____ | ____ | ____
```
