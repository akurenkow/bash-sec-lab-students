# Задание 3. Находим брутфорс в auth.log

**Что делаем:** первое настоящее обнаружение атаки — перебор паролей SSH.

Файл: `data/auth.log`.

## Шаг 1. Все неудачные попытки

```bash
grep "Failed password" data/auth.log | wc -l
```

## Шаг 2. Кто их генерирует

IP в строке стоит после слова `from`. Подвох: в строках
`Failed password for invalid user root from ...` слов до IP **на два
больше**, чем в `Failed password for admin from ...` — поэтому номер
колонки «гуляет». Надёжный способ — вырезать IP по маркеру `from`:

```bash
grep "Failed password" data/auth.log \
  | grep -oE 'from [0-9.]+' | awk '{print $2}' \
  | sort | uniq -c | sort -rn
```

Разбор: `grep -oE 'from [0-9.]+'` — вырезать из строки только кусок
«from <цифры.точки>»; дальше второе поле — сам IP.

Попробуйте для сравнения вырезать просто `$11` по номеру колонки —
увидите, почему номерное поле здесь подводит.

## Шаг 3. Ответьте на вопросы расследования

1. Какой IP лидирует по неудачным попыткам и сколько их?
2. В каком часу шла атака? (посмотрите на время в строках)
3. Был ли **успешный** вход с этого IP? ВПИШИТЕ IP:

```bash
grep "Accepted password" data/auth.log | grep "____"
```

Если успешный вход был — это уже не «попытка», а инцидент.
