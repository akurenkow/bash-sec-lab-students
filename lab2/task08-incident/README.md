# Задание 8. Мини-расследование

**Что делаем:** собираем все приёмы двух лабораторных в одно
расследование. Дан только факт: «вчера на сервере что-то случилось».

## Вводные

Файлы: `data/auth.log`, `data/access.log`, `data/intruder_history.txt`.

## Вопросы для отчёта (ответы подкрепляйте командами)

1. С каких IP-адресов были неуспешные попытки входа по SSH и сколько?
2. Был ли успешный вход с подозрительного адреса? Когда?
3. Что происходило в это время на веб-сервере (access.log)?
4. Что делал «гость» на сервере (intruder_history.txt)?
5. Ваша оценка: инцидент или ложная тревога? Что предложите сделать
   первым делом (2–3 меры)?

## Методические подсказки

- Начните с «широкого» взгляда: топ IP в обоих логах.
- Сведите события на одну временную шкалу (task05).
- Каждый вывод подкрепляйте командой — отчёт без доказательств
  не принимается.

## Результат

**В отчёт:** ответы на 5 вопросов с командами-доказательствами.
