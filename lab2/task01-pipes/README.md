# Задание 1. Конвейеры: топ IP

**Что делаем:** классическую связку аналитика логов —
`sort | uniq -c | sort -rn`.

Файл: `data/access.log` — журнал веб-сервера (учебный).

## Шаг 1. Формат строки

```bash
head -2 data/access.log
```

Первое поле — IP-адрес клиента.

## Шаг 2. Вырежем первое поле

Пока «в лоб», через cut (пробел — разделитель):

```bash
cut -d' ' -f1 data/access.log | head -3
```

## Шаг 3. Топ адресов

Соберите конвейер по частям, добавляя по одной команде и наблюдая
вывод после каждой:

```bash
cut -d' ' -f1 data/access.log | sort
cut -d' ' -f1 data/access.log | sort | uniq -c
cut -d' ' -f1 data/access.log | sort | uniq -c | sort -rn | head -5
```

Разбор:
- `sort` — сортировка (одинаковые IP встают рядом);
- `uniq -c` — склеить дубли и посчитать;
- `sort -rn` — сортировка по числу, по убыванию;
- `head -5` — пять самых активных.

## Шаг 4. Ответьте письменно

Какой IP на первом месте и почему это подозрительно
(подсмотрите, что он делал: `grep <IP> data/access.log | head`)?

## Результат

**В отчёт:** топ-5 IP и ответ из шага 4.
