# Задание 6. Первый скрипт: report.sh

**Что делаем:** собираем ручные команды из прошлых заданий в скрипт,
который сам пишет мини-отчёт по auth.log.

## Шаг 1. Заполните заготовку

Откройте `report.sh` в этой папке и ВПИШИТЕ четыре пропуска
(всё уже встречалось в заданиях).

## Шаг 2. Запустите

```bash
chmod +x report.sh
./report.sh
```

## Шаг 3. Сделайте путь к логу параметром

Сейчас файл зашит в скрипт. Улучшите: пусть скрипт принимает путь
к логу аргументом. Подсказка — первый аргумент это `$1`:

```bash
LOG="${1:-data/auth.log}"
```

(`:-` — «если аргумента нет, использовать значение по умолчанию»).
Замените в командах скрипта `data/auth.log` на `$LOG` и проверьте:

```bash
./report.sh
./report.sh data/auth.log
```

## Результат

**В отчёт:** готовый `report.sh` и вывод его работы.
