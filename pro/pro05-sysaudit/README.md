# pro05-sysaudit. Скрипт аудита системы

**Цель:** Напишите audit.sh, собирающий в отчёт: пользователи с UID 0 (должен быть один — root), пользователи с UID≥1000, процессы root не из системных путей, открытые порты (ss -tulpn или netstat), файлы без владельца в /tmp. Каждый раздел — с заголовком и датой.

## Критерий приёмки

скрипт + пример отчёта
