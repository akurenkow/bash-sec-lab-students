# pro02-suid-audit. Аудит SUID-файлов

**Цель:** Напишите скрипт, который ищет SUID-файлы в системе и сравнивает их с эталонным списком (baseline), сохранённым ранее. Первый запуск создаёт baseline, следующие — сообщают о новых SUID-файлах (которых не было в baseline). Подумайте, где хранить baseline и как сравнивать два списка (comm или diff).

## Критерий приёмки

скрипт suid-audit.sh: первый прогон создаёт baseline, после ручного добавления файла с SUID — детект
