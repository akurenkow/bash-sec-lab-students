# pro06-proc-watch. Охота за процессами

**Цель:** Скрипт-сторож: раз в N секунд снимает список процессов и сигналит, если появился процесс, которого не было в первом снимке (новые системные запуски игнорируйте по белому списку). Проверка: запустите сторож, затем sleep 5000 & — сторож должен заметить.

## Критерий приёмки

watcher.sh + лог сработки
