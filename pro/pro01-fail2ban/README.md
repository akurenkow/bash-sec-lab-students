# pro01-fail2ban. Свой fail2ban на bash

**Цель:** Напишите скрипт, который анализирует auth.log и формирует список IP для блокировки: все адреса с числом Failed password больше N (порог — аргумент скрипта, по умолчанию 10). Результат — файл blocklist.txt (один IP на строку). Бонус: скрипт принимает путь к логу аргументом 2 и работает с любым auth-подобным логом.

## Критерий приёмки

blocklist.txt + скрипт; тест на data/auth.log с порогами 5 и 40
