# pro04-integrity. Контроль целостности (мини-Tripwire)

**Цель:** Скрипт строит baseline: sha256 всех файлов в указанном каталоге → файл с суммами. При повторном запуске сообщает: какие файлы изменились, какие добавлены, какие удалены. Проверьте на data/practice_tree: измените файл, добавьте, удалите — скрипт должен всё заметить.

## Критерий приёмки

скрипт integrity.sh + демонстрация трёх видов изменений
