# pro07-access-report. Полный разбор access.log

**Цель:** Одним скриптом: топ-5 IP, распределение кодов, топ-5 запрошенных путей, список запросов к «чувствительным» путям (admin, .env, .git, backup) с IP и временем. На выходе — читаемый текстовый отчёт.

## Критерий приёмки

скрипт + отчёт по data/access.log
