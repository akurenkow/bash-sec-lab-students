# pro03-bruteforce-report. Отчёт по брутфорсу с порогом тревоги

**Цель:** Скрипт анализирует auth.log и выводит вердикт: OK, если максимум неудачных попыток с одного IP ≤ 3; WARNING при 4–10; CRITICAL при >10 или если с «грязного» IP был успешный вход. Коды возврата: 0/1/2 соответственно (так устроены плагины мониторинга Nagios).

## Критерий приёмки

скрипт с тремя уровнями + демонстрация всех трёх исходов
