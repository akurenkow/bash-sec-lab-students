# pro08-timeline. Таймлайн инцидента

**Цель:** По двум логам (auth.log, access.log) постройте единую хронологию событий с подозрительных IP: скрипт выводит строки обоих логов, отсортированные по времени, с пометкой источника [SSH]/[WEB].

## Критерий приёмки

скрипт + таймлайн по данным лабораторной
